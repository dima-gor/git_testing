# Letter grades

Write a program `grade.py` that reads one whole number from 0 to 100 (a score) and prints its letter grade:

| Score | Grade |
|---|---|
| 90 and higher | A |
| 80–89 | B |
| 70–79 | C |
| 60–69 | D |
| below 60 | F |

Put the logic in a function `letter_grade(score)` that returns the letter, and call it from your program.

Example: input `85` prints `B`.

## Grading

| Part | Points |
|---|---|
| Output: your program prints the right grade for several scores | 10 |
| Code structure: you define `letter_grade` and don't use `eval` | 10 |
