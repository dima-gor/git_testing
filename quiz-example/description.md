# Python basics quiz

This quiz has two parts:

1. **Multiple choice questions** about lists, functions and operators. Pick one answer per question.
2. **A coding question:** write a program that reads numbers and prints their total.

## Grading

| Part | Points |
|---|---|
| Multiple choice | 10 |
| Coding question: output | 10 |
| Coding question: unit tests | 10 |

The output test runs your program with a few inputs and compares what it prints. The unit tests call your function `total(numbers)` directly, so keep that name.
